# Пояснительные схемы

Схемы поясняют рисунки и рассуждения на доске; это самостоятельные иллюстрации, а не точные копии кадров. Каждая схема хранится как SVG и открывается отдельно из конспекта. Текст и формулы набраны векторно. В обозначениях совместной стратегии аргументы разделены запятой: $\mu(S,S)$, $\mu(S,G)$, $\mu(G,S)$.

Три схемы нарисованы непосредственно в SVG: сам файл содержит их редактируемый исходный код. Остальные 12 SVG воспроизводятся из [Python-кода](src/generate_board_explanations.py) с помощью Matplotlib:

```bash
python3 "lectures conspects/diagrams/src/generate_board_explanations.py"
```
