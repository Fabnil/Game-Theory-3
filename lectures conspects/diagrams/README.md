# Пояснительные схемы

Каждая схема хранится в редактируемом SVG. **SVG-файл и есть исходный код рисунка**: в нём остаются геометрия, цвета и текстовые подписи. Для формул в конспектах рядом со схемами используется LaTeX в Markdown. В обозначениях совместной стратегии аргументы разделены запятой: $\mu(S,S)$, $\mu(S,G)$, $\mu(G,S)$.

| Схема | Что поясняет | Где используется |
|---|---|---|
| [Верхняя огибающая](01_best-response-envelope.svg) | Три линейных выигрыша Боба и смена лучшего ответа при $x=1/3$ и $x=1/2$ | Лекция 1, модельная игра $2\times3$ |
| [Приватный сигнал](02_correlated-signal.svg) | Выбор профиля посредником и отдельная рекомендация каждому игроку | Лекция 2, коррелированное равновесие |
| [Порядок раунда](03_feedback-timeline.svg) | Когда среда назначает потери и чем отличается полная обратная связь от бандитной | Лекция 3, определение 15 |

Схемы можно открыть отдельно по ссылкам в конспектах или прямо здесь; VS Code показывает SVG в Markdown Preview.
